# TI-84 Evo Python scripts

This repository contains Python programs for the TI-84 Evo. The Python App uses Python syntax with calculator-specific limits. It does not use every feature from desktop Python.

## Enter significant figures with scientific notation

Use scientific notation to show trailing zeros in an input value. Type the significant digits, including trailing zeros, then press **2nd** and **comma** to enter `E`. Type the exponent after `E`.

Example: enter `1.20`, press **2nd**, **comma**, then enter `3`. The value is `1.20E3`, or `1.20 × 10^3`. The two zeros after the decimal show three significant figures.

The `E` notation records the trailing zeros in the input text. Python converts the input to a numeric value. It does not keep track of measurement precision during later calculations.

## Use the programs

- Read the README in the program's folder before you run it.
- Enter values in the units required by the equation and constants.
- Use `*` for multiplication in typed expressions.
- Check that the input values and model assumptions match your course problem.
